Review one expired council forecast without hindsight excuses.

FORECAST DATE/TIME: [timestamp]
FORECAST HORIZON/EXPIRY: [timestamp]
ASSET: [asset]
ORIGINAL REPORT: [paste or link]

Compare the forecast with the actual outcome using data available through the expiry. Report:
1. Whether the base scenario occurred.
2. Whether each stated trigger and invalidation fired, and when.
3. Directional accuracy and maximum adverse/favorable excursion, if reliable prices are available.
4. Which evidence was genuinely useful versus coincidental, stale, or double-counted.
5. Calibration: was the assigned probability defensible given the result and the evidence available at forecast time?
6. One specific prompt or process improvement. Do not rewrite the original thesis after the fact.
7. A single CSV row matching `research/forecast-ledger.csv`; append it only when explicitly asked.

This is research-process evaluation, not investment advice.
