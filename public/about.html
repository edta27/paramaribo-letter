Why this letter

Medium is a landlord. This folder is a filing cabinet. Each issue is a pair of files. New posts are added. Old posts are not removed to satisfy a filter.

The Paramaribo Letter is a static newsletter for desk notes: Bitcoin structure, event windows, and what the council actually agreed on. It is not a broker, not a Medium mirror, and not personalized advice.

How an issue survives

Every letter lives in public/issues/ as a JSON sidecar and an HTML body. That folder is the Vercel website root. The catalog is rebuilt from it. The publisher refuses to overwrite an existing id. Git keeps the history even if you never run a platform.

How to post

Open New issue, download the two files, drop them in public/issues/, then:

python3 scripts/publish_letter.py --rebuild

Or one command from notes:

python3 scripts/publish_letter.py --title "Headline" --dek "Lede" --cover images/cover-pullback.png --body-file notes.md

How to read it

From the project root:

python3 -m http.server 8766 --directory public

Then open http://127.0.0.1:8766/. Photographs in public/images/ are editorial stills generated for this letter. No issuer logos. The equity board is at /desk.

Educational scenario research only. Not financial advice. No leverage recommendation.
